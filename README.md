# orchestra-mcp/pack-extensions

Extension system skills for native, Raycast, and VS Code compatibility

## Install

```bash
orchestra pack install github.com/orchestra-mcp/pack-extensions
```

Or via MCP:
```
install_pack(repo: "github.com/orchestra-mcp/pack-extensions")
```
